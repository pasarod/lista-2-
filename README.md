# 🐍 Exercícios de Listas em Python

Resolução de uma lista com **20 exercícios práticos** sobre manipulação de listas em Python.

> **Abordagem:** O foco principal foi treinar a lógica fundamental usando laços (`for`, `while`), condicionais (`if/else`) e manipulação manual de índices — evitando atalhos prontos como `sum()`, `max()`, `min()`, `index()` e `set()` sempre que possível.

---

## 📚 Conteúdo Resolvido

| Exercícios | Tópicos Praticados |
| :--- | :--- |
| **01 — 06** | Acesso por índice, iteração, soma manual, média, maior/menor valor e contagem de pares/ímpares. |
| **07 — 12** | Busca linear, `append()`, `remove()`, ordenação (`sort` vs `sorted`), fatiamento (*slicing*) e deduplicação. |
| **13 — 18** | Filtro acima da média, *list comprehension*, listas paralelas, matrizes 3x3, 2º maior valor e frequência. |
| **19 — 20** | **Problemas reais:** controle de estoque com alerta crítico e análise de vendas semanais. |
